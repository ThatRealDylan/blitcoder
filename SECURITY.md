# BlitCoder Security

## Reporting Security Vulnerabilities

If you've found a security issue in BlitCoder, please report it responsibly:

1. **It should be a valid security issue** (not a feature request).
2. **Create a GitHub issue** and tag it with `security`.
3. **Do not post details on social media**.
4. **We cannot set an exact date on when the vulnerability will be fixed, you have to wait for a response.**

## Reporting Vulnerabilities/Malware in a Plugin

We are only responsible for featured plugins. Any third-party plugin is the sole responsibility of the plugin developer.
If you find a vulnerability or bug in a plugin, please report it to the plugin developer if possible.
